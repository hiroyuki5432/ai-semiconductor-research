# AI半導体設計・レイアウト・PDK研究ウォッチ

更新日: 2026-10-16（日本時間）

AIを用いた半導体設計、物理設計、DRC、PDK関連研究の知識ベースです。**論文の主張・確認できた実証・実務への示唆を分けて記録**します。現在は、指定された5論文を一次資料で確認しています。以前の会話で言及された「6論文」のうち残る1件は未特定です。

## 入口

- [論文比較表](COMPARISON.md) — 1行要約と、技術差分・新規性・検証レベル・実証条件・限界
- [技術成熟度マップ](MATURITY.md) — 分野別に何が実証されたか
- [論文カード](papers/) — 著者・所属・方法・評価・限界・実務への示唆
- [週次レポート雛形](templates/weekly-report.md)

## 収録基準

1. 原著論文、著者のプロジェクトページ、公開コードなど一次資料を参照する。
2. 数値には対象、評価指標、条件、出典を添える。論文の自己申告と独立再現を区別する。
3. 「シミュレーション合格」「DRC/LVS通過」「製造提出」「実チップ測定」を同義に扱わない。
4. PDKのルール記述生成、DRC違反修正、回路設計、物理設計、教育実証を別の課題として比較する。
5. 企業の非公開PDKへの適用可否は、公開ベンチマークから推定しない。判断には権利、データ保護、実ツールでの再検証が必要。
6. 週次更新では新規論文が0件でも「該当なし」と記録する。

## 更新手順

新しい論文は `papers/` のカードを作成し、`COMPARISON.md` に1行を追加します。`MATURITY.md` は単なる件数集計でなく、**その分野で新たに示された能力と残る検証**が変わった場合に更新します。週次報告では対象期間・検索先・検索語・採否理由を残してください。
